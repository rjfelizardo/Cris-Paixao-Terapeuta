# Cris Paixão Espaço Terapêutico

Site público + sistema de agendamento da Cris Paixão (Grupo Bridge).

- Next.js (App Router) + Tailwind CSS
- Telas: `/` site, `/agendar`, `/pagamento`, `/sessoes`, `/painel`
- Textos, preços e serviços marcados com [colchetes] são placeholders até o briefing da cliente.

```bash
npm install
npm run dev
```
